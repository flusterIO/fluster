# Fluster

![Fluster screenshot](apps/website/public/assets/logo/fluster_banner_with_name.png)

Free and open source academic note taking. Rust powered interactive plotting, dynamic RAG, and everything a modern researcher needs to be productive in one place... for free.

Checkout our website [here](https://flusterapp.com).

Or check out the current feature list [here](https://github.com/flusterIO)

## For Linux Users

There's currently an ongoing issue with some Linux distributions and Wayland. As I work on a mac, I'm largely relying on information from other users to figure out what works and what doesn't. Until I get this issue resolved, please checkout [this post](https://www.reddit.com/r/Fluster_app/comments/1o8gz0w/important_linux_users/) and let us know what does and doesn't work for your setup. Since I'm not working in a Linux environment, the more information I can gather from other users the quicker I can get this issue resolved.
