# Audio

Embed the controls for an Audio file directly within your notes, with the ability to link to specific timestamps within that audio file.

<Hint>
    Do not use a leading slash in your file path unless you are using an absolute path. Absolute paths are not recommended for portability reasons.
</Hint>

```jsx 
<Audio
    id="ofMiceAndMen"
    file="media/ofMiceAndMen.mp4" 
/>
```

## Props

| key | type | desc |
| --- | ---- | ---- |
| file | `string` | The path to the video, relative to your notes directory. | 
| id | `string?` | An optional string to be used in timestamp links. |

---

## Timestamp Links

<Hint>At least one `:` is required in the timestamp link. A value of purely seconds will not work.</Hint>

You can link to specific timestamps within your audio file using the special `[my link body](audio:ofMiceAndMen@48:00)`.

In this timestamp link syntax, the id field, `ofMiceAndMen` in this case, must match an audio element's id on that same page. If only a single `:` exists in the timestamp, it is interpreted as `minutes:seconds`. If two `:` exist, it is interpreted as `hours:minutes:seconds`. A value of just seconds will not work.
