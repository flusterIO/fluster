# Highlight

A <Hl>highlight</Hl> component is available under the alias `Hl`.

## Demo

<Hl warning> My highlighted text goes here. </Hl>

```jsx
<Hl warning>
    My highlighted text goes here.
</Hl>
```

## Props

> Note, this component also accepts a color property. See the embedded docs for more information.

| key | type | desc |
| --- | ---- | ---- |
| children | `ReactNode` | The highlighted text. |
