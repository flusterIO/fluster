# Hint

The `Hint` component adds some styling to a bit of text that is intended to indicate some important information that needs to stand out, but is much more subtle than a `Admonition`.


## Demo

<Hint>
        My hint goes here.
</Hint>

```jsx
<Hint>
    My hint goes here.
</Hint>
```



## Props

<Hint developer>
These props also extend `HTMLProps<HTMLDivElement>`, meaning all properties that are accepted by a div in React will be passed to the container element.
</Hint>

| key | type | desc |
| --- | ---- | ---- |
| children | `ReactNode` | The underlined text. | 
| label | `string?` | Replace 'hint' with this. | 
| note | `boolean?` | Change 'hint' to 'note' and adjust color. | 
| seeAlso | `boolean?` | Change 'hint' to 'See Also' and adjust color. |
