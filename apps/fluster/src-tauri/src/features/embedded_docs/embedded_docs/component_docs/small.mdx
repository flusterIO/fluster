# Small

The `Small` component makes text slightly smaller and allows for addtional styling.


## Demo


```mdx
This is normal text,

<Small muted_foreground>
        but this is small
</Small>
```

This is normal text,

<Small muted_foreground>
        but this is small
</Small>




## Props

> Note, this component also accepts a color property. See the embedded docs for more information.

| key | type | desc |
| --- | ---- | ---- |
| children | `ReactNode` | The underlined text. | 
| noMargin | `boolean?` | If true, will remove default margin. |
