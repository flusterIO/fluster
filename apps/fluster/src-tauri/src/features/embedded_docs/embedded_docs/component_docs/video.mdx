# Video

Display videos directly in your notes with the video component.

<Hint>
    Do not use a leading slash in your file path unless you are using an absolute path. Absolute paths are not recommended for portability reasons.
</Hint>


```jsx 
<Video
    id="susskind4"
    file="media/susskind_lecture_4.mp4" 
    sidebar
    right
/>
```

## Props

> These properties extend the `PositionableProps` object, the same as an admonition making the center, right, and sidebar properties available as well.

| key | type | desc |
| --- | ---- | ---- |
| file | `string` | The path to the video, relative to your notes directory. | 
| id | `string?` | An optional string to be used in timestamp links. |


---

## Timestamp Links

<Hint>At least one `:` is required in the timestamp link. A value of purely seconds will not work.</Hint>

You can link to specific timestamps within your video using the special `[my link body](\video\:susskind4@48:00)`. (Don't use the `\` character where it appears. This was included to avoid parsing the tags in the docs.)

In this timestamp link syntax, the id field, `susskind4` in this case, must match a video element's id on that same page. If only a single `:` exists in the timestamp, it is interpreted as `minutes:seconds`. If two `:` exist, it is interpreted as `hours:minutes:seconds`. A value of just seconds will not work.
