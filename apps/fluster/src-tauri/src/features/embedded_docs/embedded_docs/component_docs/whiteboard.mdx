## Props


| key | type | desc |
| --- | ---- | ---- |
| id | `string` | A required id field used to save and retrieve data from the database. | 
| grid | `boolean?` | Set to true to enable grid snapping. | 
| title | `string?` | An optional string used in the title bar and within search results (not yet implemented). |
