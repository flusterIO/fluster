# Color


## Demo

<Color label="Fluster" color="#0ba5e9" />

```jsx 
<Color label="Fluster" color="#0ba5e9" />
```

## Props


| key | type | desc |
| --- | ---- | ---- |
| color | `string` | Any valid css color string. | 
| label | `string?` | The label of the color. | 
| size | `number?` | Defaults to 16px. |
