# Div

This is a utility component that accepts any props that can be passed to a div in React.


## Demo

<Div id="my_id" style={{ backgroundColor: "red", color: "#fff", padding: "1rem"}}>
    This is a custom div!
</Div>

```jsx 
<Div id="my_id" style={{ backgroundColor: "red", color: "#fff", padding: "1rem"}}>
    This is a custom div!
</Div>
```

## Props

`type props = HTMLProps<HTMLDivElement>`
