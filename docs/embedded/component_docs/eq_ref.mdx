## Props


| key | type | desc |
| --- | ---- | ---- |
| anchor | `boolean?` | Set to true if the element is wrapping the equation. Leave empty or set to false if intended to insert the equation number. | 
| id | `string` | A unique string used to join the references with the anchor element. | 
| children | `ReactNode?` | The equation if `anchor = true`. |
