# Grid

## Props

```tsx 
interface ColumnMinMax {
  min: string | number;
  /// If true, will set columns to auto-fill instead of auto-fit
  autoFill?: boolean;
}

interface GridProps {
  children: ReactNode;
  gap?: string | number;
  cols: number | ColumnGroup | ColumnMinMax;
}
```


| key | type | desc |
| --- | ---- | ---- |
| children | `ReactNode` | Grid items. | 
| cols | `number | ColumnGroup | ColumnMinMax` | Grid items. | 
| gap | `string | number` | An optional number (pixels) or a valid css string. | 


# Grid Item

## Props

| key | type | desc |
| --- | ---- | ---- |
| children | `ReactNode` | Grid items. | 
| border | `boolean?` | Add a border to a grid item. | 
| center | `boolean?` | Center content within the grid item. | 


## Demo

<Grid cols={{
   min: 250,
}}>
    <GridItem border center>
        Grid item one
    </GridItem>

    <GridItem border center>
        Grid item two
    </GridItem>

    <GridItem border center>
        Grid item three
    </GridItem>
</Grid>
