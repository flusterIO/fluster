# Hint

The `Hint` component adds some styling to a bit of text that is intended to indicate some important information that doesn't needs to stand out, but is much more subtle than a `Admonition`.


## Demo

<Hint>
        My hint goes here.
</Hint>

```mdx
<Hint>
    My hint goes here.
</Hint>
```
