# Small

The `Hint` component adds some styling to a bit of text that is intended to indicate some important information that doesn't needs to stand out, but is much more subtle than a `Admonition`.


## Demo

This is normal text,

<Small muted_foreground>
        but this is small
</Small>

```mdx
This is normal text,

<Small muted_foreground>
        but this is small
</Small>
```



## Props

> Note, this component also accepts a color property. See the embedded docs for more information.

| key | type | desc |
| --- | ---- | ---- |
| children | `ReactNode` | The underlined text. |
