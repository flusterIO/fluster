# Underline

An <Ul>underline</Ul> component is available under the alias `Ul`.

## Demo

<Ul success> My underlined text goes here. </Ul>

```jsx
<Ul success>
    My underlined text goes here.
</Ul>
```

## Props

> Note, this component also accepts a color property. See the emdded docs for more information.

| key | type | desc |
| --- | ---- | ---- |
| children | `ReactNode` | The underlined text. |
