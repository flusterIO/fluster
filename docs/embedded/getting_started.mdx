# Getting Started

Fluster aims to be an accessible presentation layer for whatever you need to jot down, organize and reference later. To accomplish this, Fluster relies on `.mdx` as the most commonly used input. [Mdx](https://mdxjs.com) works as a superset of markdown, allowing all of the familiar markdown features with the added support for React components.

Fluster then embeds this React app in a Rust powered tauri application, stores your notes in a local database and uses (for now, local only) AI to provide you with insights into your data that no other app offers.


## First Steps

When Fluster is first launched, an onboarding screen should be presented, asking among other things where you plan to keep your notes. For portability, Fluster insists that you keep all of your notes within a single parent directory, but notes can be organized within this directory however you like, including within deeply nested folders.

### Create your first note

<Hint>
Fluster does provide a built in code editor with some additional features specific to the functionality of Fluster, but at the time of release _new_ notes must be created manually.
</Hint>

To create a note, you can use any code or text editor you like. Just create a file with the `.mdx` extension anywhere within the directory you provided to Fluster.

### Front Matter

Mdx uses a `yaml` like syntax to define what is known as _front matter_.

To define your own front matter, the title of your note in this case, start your note with:

```json
{
"title": "My title"
}
```

Now, open the command palette within Fluster using cmd+p, and choose `Sync Database` to generate the database entities related to your note.

You can continue working on any note within your directory, without updating your database again. However, the database is used directly for most search and AI related tasks, so updating it frequently will make sure that these tasks perform as expected.

Once the note is created, an editor can be opened in split-view from the command palette when you are already viewing that note, or you can continue editing the note in your favorite code/text editor. While the capabilities of Fluster will continue to grow rapidly, Fluster aims primarily to provide a uniform set of components, an API and a powerful UI so that you can organize your thoughts however you see fits; it does not presume that you use the editor provided by Fluster.


<Hint>
    Use the command palette often, and check the side panels on various pages. Most of the functionality of assumes that the user will learn the keyboard shortcuts to toggle the left and right panel, as well as the command palette. You can navigate within the command palette with either the arrow keys or **tab** and **tab-shift**.
</Hint>

## Related Data

> For now, while the rewrite in Rust is wrapping up, there are quite a few half-implemented features. I am releasing this application early in the hopes of promoting the modified model of relativity that inspired the creation of Fluster, but full functionality will be available this summer. While Fluster is in this beta phase, some auxillary data (snippets, equations, task lists) may be lost when upgrading to a new version. Nothing that is on your file system or that can be derived from what is already on your file system will be affected in anyway, but data entered manually through the UI will likely grow to become incompatible with some of these models before this rewrite is through.
