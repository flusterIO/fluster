---
title: Environment Variables
---

> Most of these environment variables only pertain to those contributing to Fluster directly. These variables will have no effect for those building plugins or simply using Fluster.

| Env Var | What it does | Default |
| ------- | ------------ | ------- |
| `FLUSTER_DATABASE_PORT` | Specifies the port that the embedded database server will expose itself on. | 21521 |
